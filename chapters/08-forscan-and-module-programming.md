# 8. FORScan & Module Programming

## Recovery-first workflow

- Create and retain original As-Built/module backups before making changes.
- Log every change with before/after values, rationale, tool/interface version, and verification result.
- Use the camera configuration reference only for a documented camera/APIM/BCM situation; avoid changing unrelated configuration values.
