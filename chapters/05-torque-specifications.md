# 5. Torque Specifications

## Source and scope

Torque values are from the **2024 F-350 Super Duty 7.3L Workshop Service Manual (REF-028)**, extracted 15 September 2026. Ford does not publish one torque table. Each value sits inside the repair procedure that uses it, so these were pulled procedure by procedure and filtered to this truck's configuration:

- **7.3L gasoline V8**, 10R140 transmission;
- **4x4**, single rear wheel;
- **Dana M235 front axle**, **Ford 11.6 in rear axle**.

Values for the 6.7L diesel, the 6.8L, DRW and F-450/F-550 variants, and the Dana M275/M300/M315 axles were excluded.

> **Read the procedure before tightening anything safety-critical.** This chapter records the number; the WSM procedure records the conditions around it. That includes bolt sequences, one-time-use (torque-to-yield) fasteners, thread locker or lubricant requirements, and whether the vehicle must be resting on its wheels. Where a fastener is marked **new**, Ford directs it be replaced, not reused. **Do not infer a specification for an unlisted fastener.**

**Units.** lb-ft for large values and lb-in for small ones, as Ford lists them, with N·m in brackets. A **staged** value is tightened in the order given; an angle (for example **+90°**) is turned after the preceding torque step.
